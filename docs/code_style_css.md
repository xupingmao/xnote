# CSS代码规范

* 不建议使用ID选择器
* `*-style`用于解决命名冲突问题，不设定任何独立的样式
* 使用横线`-`而不是下划线`_`
    - 正例: `tab-box`
    - 反例: `tab_box`
* 建议使用多个class组合而不是一个长class
    - 正例: `tag red`，如果`red`冲突了可以使用`tag red-style`
    - 反例: `red-tag`
    - 特殊情况: 名称冲突时使用长名称
* 类型放在后面
* 常用的命名
    - 导航: `nav`
    - 页头: `header`
    - 页脚: `footer`
    - 容器: `container`, `box`
    - 尺寸: `xs/sm/md/lg/xl` (extra small/small/medium/large/extra large)

## px 间距规范（最小单元 = 8px）

> 背景：项目原有间距以 5px 占多数，但 5 是奇数、不属于通用设计规范；先试用 4px 偶数栅格，视觉上过紧，故最终采用 **8px 偶数栅格**（Tailwind / Bootstrap / Material 通用做法），与 `12/14/16/20/24` 字号及行高形成整齐垂直韵律，且比 4px 更舒展、可读性更好。

* **最小单元（base）**：`8px`，另设 `4px` 半步（half-step）。偶数基准，避免与 1px 边框叠加产生亚像素模糊。
* **允许取值（8px 栅格 + 4px 半步）**：
  `0, 4, 8, 16, 24, 32, 40, 48, 56, 64, 72, 80, 96, 104, 120, 160, 200, ...`
  - `4px` 半步仅用于**紧凑组件的微调**（按钮/标签/行内元素的内边距与外边距、小圆角），不要在大块布局间距上滥用。
  - 取整规则：`1~6px → 4px`，`7px → 8px`；≥8 的值落到最近的 8 倍数，正好居中（如 12/20/28/36…）时**向上取整**（保持布局不收得过紧）。例如 `3→4`、`5→4`、`10→8`、`15→16`、`25→24`、`30→32`、`50→48`、`100→104`。
* **分类约束**：
  - 间距 `margin` / `padding` / `gap` 及其方向：必须取 8px 栅格（紧凑组件允许 4px 半步）。
  - 定位 `top` / `left` / `right` / `bottom` / `inset*`：取 8px 栅格。
  - 字号 `font-size`：走 2px 步进 `12/14/16/18/20/24/30/36`，不出现 13/17 等奇数。
  - 行高 `line-height`：取 8 的倍数（`16/24/32/40/48/104...`）。
  - 圆角 `border-radius`：`0/4/8/16/24`（小圆角统一用 4px 半步），pill 用 large 圆角。
  - 边框 `border-width`：`1px` 默认、`2px` 强调（不参与间距栅格，边框本就是奇数属正常例外）。
  - 尺寸 `width` / `height` / `min-*` / `max-*`：组件实际需求，建议取偶数（8 的倍数优先），不强制定网格。
* **命名建议（可选）**：间距可用语义类 `xs(4) / sm(8) / md(16) / lg(24) / xl(32)` 或 CSS 变量 `--space-1=4px ...`，减少魔法数字。
